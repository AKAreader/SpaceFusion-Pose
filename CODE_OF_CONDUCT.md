# Code of Conduct

## Expected Behavior

- Be respectful and constructive.
- Discuss technical disagreements with evidence and context.
- Keep issues and pull requests focused on the project scope.
- Respect privacy around datasets, credentials, and unpublished research materials.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private data, credentials, tokens, or sensitive project materials.
- Misrepresenting experimental results or project validation status.
- Repeatedly derailing technical discussions.

## Reporting

If you see behavior that does not fit this code of conduct, report it through the repository maintainer contact channel or a private communication channel when available. Do not disclose private or sensitive details in public issues.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, and related project communication spaces.

## Enforcement

Maintainers may edit, close, or remove issues and pull requests that violate these expectations. Serious or repeated violations may lead to restricted participation.
