# SpaceFusion-Pose v0.1.0

Release date: 2026-08-01

## Overview

`v0.1.0` is the first public research release of SpaceFusion-Pose, a research-oriented framework for infrared-visible spacecraft perception, image fusion, synthetic data organization, and pose-oriented evaluation.

This release establishes a maintainable public repository baseline. It does not represent validated flight software or a production inference package.

## Highlights

- Deterministic zero-data CPU Quick Start.
- Synthetic aligned visible/infrared sample generation.
- Transparent luminance/infrared baseline preview.
- Manifest, pose annotation, resolved configuration, and run-summary generation.
- Standard-library unit tests and GitHub Actions validation.
- Research model and dataset cards.
- Configuration, reproducibility, entry-point, roadmap, and path-audit documentation.
- Citation, contribution, security, issue, and pull-request maintenance files.
- Git LFS support for research checkpoint artifacts.

## Public Quick Start

After installing the lightweight dependencies:

```powershell
python examples/quick_start_demo.py
```

The command generates deterministic synthetic inputs and a baseline preview under:

```text
outputs/quick_start/
```

The Quick Start:

* does not require a real dataset;
* does not require a GPU;
* does not require PyTorch;
* does not download external resources;
* does not load model checkpoints;
* does not perform SoPD-Net or SeAFusion trained-model inference.

## Validation

The release is covered by the repository's `Smoke Check` GitHub Actions workflow, including:

* public Quick Start execution;
* Quick Start unit tests;
* repository smoke checks;
* example dataset configuration validation.

Local release preparation also validates:

```powershell
python examples/quick_start_demo.py --output-dir outputs/release_validation --size 128 --seed 42
python -m unittest tests.test_quick_start_demo
python examples/quick_smoke_check.py
python tools/validate_config.py --config configs/example_dataset.yaml
```

## Research Scope

The repository includes experimental scripts for:

* infrared-visible image fusion;
* synthetic spacecraft data organization;
* pose-oriented supervision and evaluation;
* qualitative and quantitative analysis;
* multiple experimental routes such as `PlanA`, `PlanD`, and `PlanA_RGB`.

These scripts may require local datasets, manifests, annotations, checkpoints, and path configuration.

## Known Limitations

* The full simulation dataset is not included.
* Some legacy scripts contain machine-specific path assumptions.
* Checkpoints do not guarantee full experiment reproduction without matching data and configuration.
* The synthetic Quick Start is not a research benchmark.
* No fixed benchmark score is claimed by this release.
* The repository is not validated for autonomous spacecraft navigation or safety-critical use.
