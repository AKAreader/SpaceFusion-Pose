# Rendering Pipeline Notes

This document is a placeholder for documenting the Blender-based visible/infrared rendering workflow.

## Current Status

The branch currently stores Blender assets and scene files. A fully automated rendering pipeline is not yet documented.

## Recommended Documentation Items

Future updates should document:

- Blender version
- Required add-ons
- Scene organization
- Spacecraft model sources
- Visible rendering settings
- Infrared/material rendering assumptions
- Camera pose sampling
- Lighting and phase-angle settings
- Export format
- Annotation export format

## Relationship to Pose-Oriented Research

The simulation assets are intended to support paired visible/infrared data generation for spacecraft perception and pose-related evaluation.

## Limitations

The current assets should be treated as research materials. They should not be interpreted as a validated physical sensor simulator without further calibration and validation.
