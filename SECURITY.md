# Security Policy

## Supported Scope

This repository contains research software, documentation, examples, and configuration templates for infrared-visible spacecraft perception and pose-oriented fusion. It is not operational spacecraft software.

## Reporting a Security Issue

If you believe you found a security issue in scripts, configuration handling, CI, or repository maintenance files, contact the maintainer privately when possible. Include a concise description, affected files, reproduction steps, and potential impact.

## What Not to Report Publicly

Do not submit the following through public issues:

- Private credentials or access tokens.
- Private datasets or sensitive mission data.
- Internal network paths or private storage locations.
- Large model checkpoints or generated experiment outputs.

## Data and Model Safety Notes

Model checkpoints are research artifacts. Dataset paths and manifests may refer to local simulation data that is not bundled with the repository. Review files carefully before sharing configs, logs, or screenshots.

## Limitations

The repository does not provide security response guarantees or operational assurance. Security-related reports will be handled on a best-effort basis.
